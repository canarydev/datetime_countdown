Datetime Countdown Widget

Display a live countdown for Datetime fields in Odoo forms, lists, and kanban cards.

Less than 24 hours is shown as HH:MM:SS; longer ranges are shown as days, months, or years.

Expired values are highlighted, and empty values show “No limit”.

Use it with widget="datetime_countdown" on any datetime field.

Also supports datetime_countdown_widget as a compatibility alias.

Lightweight, real-time, and ready for Odoo 18.
